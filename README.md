Готовые материалы для проведения тренинга: теория и практические упражнения находятся в одном репозитории.

- [Теория: день 2](theory/day2/)
- [Упражнения на Python](practice/python/)
- [Упражнения на Go](practice/go/)

## Быстрый старт

```bash
git clone https://github.com/nchursin/ut-tdd-training-multilang.git
cd ut-tdd-training-multilang
```

Каждое упражнение в `practice/python/` или `practice/go/` открывается в IDE как отдельный проект. Инструкции по настройке и запуску находятся в README соответствующего упражнения.

В стартовом состоянии тесты Gilded Rose намеренно красные: placeholder-тесты являются частью каты, а не ошибкой окружения.
