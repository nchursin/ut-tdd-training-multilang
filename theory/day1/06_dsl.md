# Качество тестов: DSL
Timing: 45 min

Мы сделали проще и легче с фикстурами. Но тесты всё ещё могут остаться техническими. Как сделать так, чтобы тесты стали вашими требованиями, и все в вашей команде могли читать их?

### Флип: Польза DSL

- Общий язык
   - Тесты читаемые для любого, кто знаком с предметной областью
- Тесты легко писать
    - Create. подскажет какие сущности есть в вашем домене
    - Create.entity() создаст билдер для валидной сущности
    - Create.entity(). подскажет как можно параметризовать сущность через билдер
    - Create.entity().please() вернет сущность из билдера
    - Скрытие данных: в тесте только то, что важно для теста
    - Легко расширять по аналогии
- Примеры DSL
   - player.buy(FIVE_CHIPS)
   - game.bet(player, THREE_CHIPS_ON_7)
   - Create.player()
   - Create.player().with_five_chips().build()
   - Create.game().with_six_players().please()
   - assert player.balance() == 2_CHIPS
   - Assert.player_has_exactly_chips(player, TWO_CHIPS)

### Проектор: Практика. Упражнение про кассовый чек

```
Наименование товара         Кол-во         Цена            Стоимость

Ноутбук                       2        45000.00 руб       90000.00 руб
Мышь                          3         1500.00 руб        4500.00 руб
......................................................................
Итого                                                     94500.00 руб
Скидка 15%                                               -14175.00 руб
Налог NV 8.0%                                             +6426.00 руб
......................................................................
Общая сумма                                               86751.00 руб
```

Мы производим кассовый аппарат, способный выдавать чеки.
Принимает от пользователя 4 параметра для одного или нескольких товаров:
 - Название
 - Количество
 - Цена
 - Буквенный код штата

По общей цене без налога мы можем рассчитать скидку.
| Сумма заказа | Ставка скидки |
| --- | --- |
| > 1000 | 3% |
| > 5000 | 5% |
| > 7000 | 7% |
| > 10000 | 10% |
| > 50000 | 15% |

По заданным 2-буквенным кодам штата мы можем рассчитать ставку налога.
| Штат | Ставка налога |
| --- | --- |
| UT | 6,85% |
| NV | 8,00% |
| TX | 6,25% |
| AL | 4,00% |
| CA | 8,25% |
