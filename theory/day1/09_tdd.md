### Варианты
- CCC TTT
    - Отложенный фидбэк
    - Небезопасный рефакторинг
    - Нетестируемый big ball of mud
- TTT CCC
    - Просто не надо
- CT CT CT
    - Нетестируемый код
    - Отдельный навык, как нарезать на такие кусочки
    - Когда C, приходится сразу решать: API, I/O, Impl
    - Когда T - скучно, и только после теста можно безопасно рефакторить
- TC TC TC
    - Естественная нарезка на кусочки
    - Тесты становятся требованиями
    - Код сразу тестируемый
    - Когда T - решаешь про I/O, API в любом порядке
    - Когда C - пишешь Impl и можно безопасно рефакторить

## Тесты как обратная связь
### Проектор: Обратная связь
Тесты — это обратная связь про то, что код ведет себя в соответствии с нашими ожиданиями

  
![xp_feedback_loops](assets/xp_feedback_loops.jpeg)

Инкрементальная итеративная разработка

### Флип: Red Green Refactor
#### Мантра TDD
- Red – Green – Refactor
- Скорость отработки тестового набора как предусловие практики TDD

### Флип: 3 закона TDD
#### 3 закона TDD
1. Не пиши больше одного красного теста. Красный тест должен падать по ожидаемой причине.
    - Ошибки компиляции, падение с исключением — не ожидаемые причины
2. Не пиши код, пока нет красного теста, который вынуждает тебя это сделать.
3. Не пиши больше кода, чем нужно, чтобы сделать красный тест зеленым.
  
![tdd meme](assets/tdd_meme_2.png)
  
### Флип: 3 способа озеленить тест
#### 3 способа сделать красный тест зеленым
- Fake it (Хардкод)
- Очевидная реализация (Просто напиши код, если он простой)
- Триангуляция (Чтобы сделать код более общим, напиши тест для нового сценария)

## Проектор: Демо. Упражнение про кассовый чек

```  
Наименование товара         Кол-во         Цена            Стоимость   
  
Ноутбук                       2        45000.00 руб       90000.00 руб
Мышь                          3         1500.00 руб        4500.00 руб
......................................................................
Итого                                                     94500.00 руб
Скидка 15%                                               -14175.00 руб
Налог NV 8.0%                                             +6426.00 руб
......................................................................
Общая сумма                                               86751.00 руб
```  

Мы производим кассовый аппарат, способный выдавать чеки.
Принимает от пользователя 4 параметра для одного или нескольких товаров:
 - Название
 - Количество 
 - Цена
 - Буквенный код штата

По общей цене без налога мы можем рассчитать скидку.                          
| Сумма заказа | Ставка скидки |
| --- | --- |
| > 1000 | 3% |
| > 5000 | 5% |
| > 7000 | 7% |
| > 10000 | 10% |
| > 50000 | 15% |

По заданным 2-буквенным кодам штата мы можем рассчитать ставку налога.
| Штат | Ставка налога |
| --- | --- |
| UT | 6,85% |
| NV | 8,00% |
| TX | 6,25% |
| AL | 4,00% |
| CA | 8,25% |

**Алгоритм работы:**

- Сделать так, чтобы он компилился (тест должен падать по правильной причине)
- Позеленить тест
- Порефакторить
