# Практика 02

Реализуйте Stock Portfolio по ATDD с помощью AI-агента.
- Давайте агенту детали, как спроектировать Acceptance-тест, проверяйте его падение.
- Следуйте двойному циклу TDD и напишите реализацию через unit тесты, останавливаясь на фазе рефакторинга и челенджа AI
- Продолжайте пока не позелените acceptance test, сделайте необходимый рефакторинг
- Переходите к следующему acceptance test
