# Roll Dice Game

## ВАЖНО!

При первом знакомстве с кодом через тесты покрывайте самую важную часть функционала, чтобы лучше познакомиться с упражнением.

## Запуск

Требуется Go 1.23+.

```bash
cd go/01_dices
go test ./...
```

Работайте короткими циклами Red–Green–Refactor. В стартовом коде генератор случайных чисел связан с игрой напрямую; нужный для тестов seam участники создают в ходе упражнения.
